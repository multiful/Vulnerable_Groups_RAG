## Anti-Patterns Verdict

**LLM assessment**: Structural skeleton (page-header → content card → nav buttons) is identical across all three pages and reads as template-generated scaffolding. 43-domain, 142-job taxonomy in InterestSelection is a database poured onto a screen. Recommendation page-desc is a template fill-in. However, safety gate at question 10, STAGE_INTRO copy, and buildDimensionReason() are genuinely authored. Net verdict: AI-scaffolded structure with genuine human touches at the emotionally critical moments.

**Deterministic scan**: Detector returned exit 0, zero findings. Confirms prior work sessions removed all pattern-detectable anti-patterns. Remaining issues are higher-order (copy, emotional safety, information architecture) rather than pattern-level slop.

## Priority Issues

**[P0] Recommendation page exposes "4단계 (은둔 청년)" in page-desc**
- RISK_LABEL in Recommendation/index.tsx still maps stages to clinical strings. Renders in page-desc inside <strong>. Most stigmatized label in Korean social services — highest tab-close risk in the flow.
- Fix: Delete RISK_LABEL. Share RISK_STAGE_LABELS from InterestSelection (user-language strings) via shared src/constants/stageLabels.ts.
- Command: /impeccable clarify

**[P0] B12_9 skip path breaks safety chain**
- Clicking "이 문항은 건너뛸게요" sets B12_9: 0 and does NOT set safetyFlag. A user who skips because they ARE experiencing suicidal ideation receives no safety banner.
- Fix: On skip, do not insert B12_9: 0. Exclude from TOTAL_MAX. Set safetyFlag = true on skip. Show support banner with softer framing.
- Command: /impeccable harden

**[P1] Arrow-key navigation auto-advances survey question (WCAG 3.2.1)**
- onKeyDown ArrowDown/ArrowRight calls select() which schedules setCurrent advance after 260ms. Keyboard users accidentally advance before choosing.
- Fix: Arrow keys only move focus. Select() only fires on onClick and onKeyDown checking Enter/Space.
- Command: /impeccable harden

**[P1] --secondary === --primary destroys grade-tier color grammar**
- index.css: --secondary: #2563eb identical to --primary: #2563eb. gradeBadgeClass() badge-primary and badge-secondary both render cobalt blue. Grade tiers 기술사/기사 indistinguishable.
- Fix: Set --secondary: #0ea5e9 and --secondary-light: #e0f2fe in index.css.
- Command: /impeccable colorize

**[P1] Completion badge "참고용 결과입니다" undermines survey payoff**
- First label after 12 difficult questions including B12_9 is a legal disclaimer. Peak-end rule violation.
- Fix: Badge text → "✓ 12개 질문 완료". Move disclaimer below CTA as small footnote.
- Command: /impeccable clarify

**[P1] policy-classify-char exposes clinical third-person research language**
- STAGE_POLICY.characteristic for stage 3/4: "비자발적인 상태입니다", "은둔과 사회활동을 반복하는 상태입니다". Reads like a clinical chart.
- Fix: Rewrite in first-person soft language. Remove 지원 전략 row (intake-worker vocabulary).
- Command: /impeccable clarify

**[P2] --text-light (#94a3b8) fails WCAG AA contrast (~2.76:1 on white)**
- Used on result-cat-pct, policy-source-text, policy-card-toggle, hyde-sources-toggle. AA requires 4.5:1.
- Fix: Change --text-light to #6b7280 or #64748b.
- Command: /impeccable audit

**[P2] Evidence modal is a single-scroll information avalanche**
- AI reasoning + DAG flow + evidence rows + exec panel (시험일정/채용행사/훈련과정/자격정보) all in one modal.
- Fix: Tab navigation: Tab 1 "왜 추천됐나요" (default), Tab 2 "시험 정보", Tab 3 "취업·훈련".
- Command: /impeccable distill

**[P2] No pre-survey consent or privacy framing**
- Survey collects suicidal ideation frequency, depression data, economic hardship — with no purpose/privacy screen before question 1.
- Fix: Add a single interstitial screen before Q1: purpose, data handling statement, voluntary nature, single CTA.
- Command: /impeccable onboard

**[P3] .card:hover lift fires on survey question cards during sensitive reading**
- index.css .card:hover translateY(-2px) applies to survey-card. Motion distraction while reading depression/suicidality questions.
- Fix: Scope hover lift to .card.clickable:hover only. Add explicit 'clickable' class where intended.
- Command: /impeccable polish

**[P3] job-toggle-btn and hyde-sources-toggle missing aria-expanded**
- InterestSelection job section toggle and RiskAssessment hyde-sources-toggle lack aria-expanded. Screen reader cannot announce state.
- Fix: Add aria-expanded={jobSectionOpen} and aria-expanded={showEvidenceSources} respectively.
- Command: /impeccable harden
