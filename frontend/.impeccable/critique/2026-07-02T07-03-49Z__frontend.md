## Priority Issues

**[P0] 260ms auto-advance removes answer correction agency**
- setTimeout auto-advance (line 509) fires before anxious/imprecise users can confirm intent. Can't correct mis-tap on depression/suicidality questions before next screen appears.
- Fix: Remove setTimeout. Auto-focus "다음" button after selection. Let user press deliberately.
- Command: /impeccable harden

**[P0] Safety banner creates emotional whiplash above CTA**
- DOM order: positive headline → red AlertTriangle safety banner → CTA buttons. Crash from encouragement to clinical alert between adjacent elements.
- Fix: Move banner below CTAs. Soften palette to warm teal/cobalt-light. Replace AlertTriangle with Phone/heart icon. Reframe copy to supportive rather than alarming.
- Command: /impeccable harden

**[P0 carry-forward] Recommendation page renders "4단계 (은둔 청년)" in bold page-desc**
- RISK_LABEL still maps clinical strings. Most stigmatized label in Korean social services in the final page the user sees.
- Fix: Delete RISK_LABEL. Share RISK_STAGE_LABELS from InterestSelection via src/constants/stageLabels.ts.
- Command: /impeccable clarify

**[P1] --secondary identical to --primary collapses secondary visual register**
- index.css L11-13: --secondary: #2563eb = --primary: #2563eb. Job/domain distinction collapses throughout InterestSelection and Recommendation grade badges.
- Fix: --secondary: #0ea5e9, --secondary-light: #e0f2fe, --secondary-glow: rgba(14,165,233,.18).
- Command: /impeccable colorize

**[P1] Policy card characteristic text is clinical third-person deficit description**
- Stage 3/4 texts use "비자발적인 상태입니다", "외부 접촉을 최소화하며 특정 공간에서만 생활하는 상태입니다".
- Fix: First-person future-oriented rewrites. Remove 지원 전략 row.
- Command: /impeccable clarify

**[P1] Safety gate uses success-green palette for a gravity-signal moment**
- Hardcoded #f0fdf4/#86efac (Tailwind green) on gate before B12_9 — signals celebration, not gravity. Bypasses tokens, breaks dark mode.
- Fix: Use --warning-light (#fef3c7) + amber border. Remove 🤝 or replace with calmer icon.
- Command: /impeccable clarify

**[P1] CertCard nested interactive elements (WCAG 4.1.2 violation)**
- div[role="button"] wrapping real <button className="roadmap-btn"> in Recommendation ~L344-395. Two conflicting Tab stops.
- Fix: Remove role="button" from outer div. Make card navigation pattern keyboard-clean.
- Command: /impeccable harden

**[P2] Survey question order: cumulative deficit priming before mental health questions**
- 관계망 → 활동 → 노동경제 → 정신건강 sequence. 6 deficit questions before depression/suicidality items.
- Fix: Insert micro-pause screen between 노동경제 and 정신건강, or reorder with buffer category.
- Command: /impeccable harden

**[P2] B12_9 skip inserts score 0 — treats skip as "no ideation"**
- L1275: B12_9: 0 on skip. User who skips due to distress scores same as user with no ideation.
- Fix: Treat skip as undefined (exclude from TOTAL_MAX). Set safetyFlag=true on safetyKey skip.
- Command: /impeccable harden

**[P2] "참고용 결과입니다" combines celebration with disclaimer in completion badge**
- Badge conflates celebratory count with medical caveat.
- Fix: Badge → "✓ 12개 질문 완료". Disclaimer → small footnote below CTA.
- Command: /impeccable clarify

**[P1] domain group headers in InterestSelection lack aria-expanded**
- .group-header buttons show ChevronUp/Down but no aria-expanded. Screen reader users cannot determine state.
